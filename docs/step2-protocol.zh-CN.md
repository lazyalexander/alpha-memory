# 第二步开发消融协议

[English](step2-protocol.md) · **简体中文**

状态：实现及 81 项测试通过；协议在首轮模型试运行前记录。
本轮使用已有有限配对任务验证实验管线，不作为一般记忆效果的未见评测证据。

## 四组定义与归因范围

| 组 | 模型可见的跨会话信息 | 修订准入 |
| --- | --- | --- |
| A | 上一模型写的进展、下一步、判断摘要，以及结论句柄 | 不强制补读，不提供先前原文检索 |
| B | A＋显式读取原定义、检查回执 | 不强制补读 |
| C | B＋原生支持状态、版本／来源绑定及解释 | 不强制补读 |
| D | 与 C 相同的信息 | 修订前强制读取当前前任原文 |

四组内部共用原生账本、不可变身份、领域检查器、范围／推导校验和来源权限。
因此测量的是“暴露给模型的记忆信息”和“补读准入策略”，不是 Rust 与其他引擎的
差异，也不能单独归因于底层不可变版本存储。C 同时增加计算状态和来源解释，
本轮不能进一步区分这两项的独立贡献。

A 仍可读本会话新建的原文，并使用相同的科学检查工具。
摘要直接使用上一模型在交接中写的进展、下一步和判断，包括可能错误的判断。
不增加另一个摘要模型；摘要生成属于正常交接调用，token 纳入成本。
A/B 不接收宿主计算的状态。结论句柄不等于原文读取。

## 试运行冻结项

- Qwen3-30B-A3B-Instruct-2507 Q8_0，固定权重 SHA-256，非思考模式。
- 原有限配对任务及阶段工作；三个新进程、空对话历史，仅通过显式交接延续。
- 共用工具 schema 和说明，只有记忆能力 JSON 因组别不同，这是有意的干预。
- 工具反馈 v2；温度 0.6、top-p 0.95、每次输出最多 1,024 token；
  `cache_prompt:false`；固定本地服务设置。
- 动作预算 10／12／14；拒绝、格式修复和模型请求失败都消耗动作。
  截断或传输失败结束阶段，不额外加步或人工补交接。
- 使用已用于回归的种子 43、44。顺序为 A43、B43、C43、D43、D44、C44、B44、A44。
  第二个种子反转组别顺序，但这不是大样本随机研究。
- 校验模型、引擎和服务设置；归档源码，单格从归档执行；推理前记录预注册摘要。
  八格全部保留，包括失败和不完整运行。

保留原十项评分器，分数只作描述。它包含 A 组无法使用的读取行为标准，
不能直接用总分给四组排名。

## 通用结果指标

记录三个阶段共 15 个必需结论判断、缺失的判断／结论、没有依据却标为 verified 的
升级、误伤独立结论、三次交接完成情况，以及固定任务最终的实际证据状态。
缺失工作单列，不能把没有输出当作零错误成功；完成情况和判断正确性一起报告。

另报来源／引用拒绝、A 组历史检索不可用拒绝、格式错误、致命后端错误、模型失败、
主动读取、拒绝后补读和剩余预算。分别记录宿主强制与模型主动行为。

成本包括模型请求尝试、已返回 usage、输入／输出 token、模型调用耗时、单格运行器
总耗时、原生 CLI 耗时及数据库大小。没有返回 usage 的请求标为未知，不能记为免费。
单格运行器总耗时不含共用模型摘要校验／服务启动和运行后审计，不隐藏额外摘要调用。

## 隔离与 report 材料

公开观察采用字段白名单。A/B 不能从恢复、读取、交接或允许引用提示中得到原生状态。
A 的检索拒绝不返回旧原文；模型写错的摘要原样保留；只有 D 强制补读；
不能跨组恢复交接包。

每格保留请求尝试（含传输失败）、原始模型回复、实际公开观察、私有原生观察、
CLI 回执、原事件／数据库、模型摘要、阶段结果、日志和源码快照。
审计核对模型实际上下文与公开历史、公开／私有投影，独立重算结果指标，
并在空数据库复放私有原生回执。阶段结束后的 oracle 不返回模型，也不用于补续会话。

只推送代码、合成夹具、协议和白名单统计。原始对话、本机路径、模型及运行材料留本地。

## 解释边界与下一道门槛

一个已知任务的八格试运行可验证对照管线并发现失败，不能证明统计优势或一般化。
不能在这些结果上反复调提示后再称为未见评测。审计完成后，另行冻结未见任务和种子；
尚未运行的双重依据任务继续保留。
