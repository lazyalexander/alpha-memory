判断及 claim 句柄；B 增加原文检索；C 增加计算状态、版本来源绑定及解释；
D 再加修订前强制补读。A 可以读取当前会话原文。

与准入策略，不能分离存储引擎效果；C 内几种信息的独立作用也未拆分。

llama-server 使用非思考模式、16,384 上下文、单并发、99 GPU 层、8 线程、
batch 512 / microbatch 256、cache RAM 0，禁用上下文滑动。
温度 0.6、top-p 0.95、单次响应上限 1,024、`cache_prompt:false`、反馈 v2
及动作预算 10/12/14 固定。完整模型、二进制、源码和预注册哈希见汇总文件。

此处“预注册”指本地推理前哈希冻结，并未提交外部注册平台。
每批推理前冻结提示和源码，顺序为 A43/B43/C43/D43/D44/C44/B44/A44。
每格三个新进程、空消息历史，只经显式交接传递工作。摘要由模型在正常交接
中生成并计入 token，无额外摘要调用；事后评分真值不提供给后续推理。
种子 43/44 和任务此前已经用于开发；两批提示分别报告，不合并成十六次独立实验。
